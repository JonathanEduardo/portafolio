# Mi Portafolio

Este es mi portafolio personal alojado en GitHub Pages.

## Cómo configurar GitHub Pages

1. Crea un repositorio en GitHub llamado `tuusuario.github.io` (reemplaza `tuusuario` con tu nombre de usuario de GitHub).
2. Sube los archivos de este proyecto al repositorio.
3. Ve a Settings > Pages y selecciona la rama `main` como fuente.
4. Tu sitio estará disponible en `https://tuusuario.github.io`.

Si quieres usar un repositorio con otro nombre, configura Pages para usar la carpeta `docs` o la rama `gh-pages`.

## Personalización

Edita `index.html` para cambiar el contenido, `styles.css` para el estilo y `script.js` para la funcionalidad.

## Estructura de Proyectos

Los proyectos están organizados en la carpeta `proyectos/`. Cada proyecto tiene su propia subcarpeta con:
- `descripcion.txt`: Archivo de texto con la descripción del proyecto.
- `imagen.svg`: Imagen representativa del proyecto (puedes reemplazarla con una imagen real).

> Nota: Algunos proyectos son privados, por eso el código no está publicado. En su lugar, se muestran descripciones técnicas y ejemplos representativos.

Para agregar un nuevo proyecto:
1. Crea una nueva carpeta en `proyectos/` (ej. `proyecto4`).
2. Agrega `descripcion.txt` y `imagen.svg` dentro de la carpeta.
3. Actualiza `index.html` para incluir el nuevo proyecto en la sección de proyectos.
